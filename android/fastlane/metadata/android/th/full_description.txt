Comics Editor คือเครื่องมือสำหรับสร้างการ์ตูนแอนิเมชันหลายภาษาและปริศนาแบบอินเทอร์แอกทีฟ — หนึ่งโปรเจกต์ หนึ่งไฟล์แบบพกพา เล่นได้ทุกที่

สร้างหน้าจากเลเยอร์ (พื้นหลัง ตัวละคร บอลลูนคำพูด คำบรรยาย เสียง) แล้วทำให้มีชีวิตด้วยแอนิเมชัน Translate, Rotate, Scale และ Alpha บนไทม์ไลน์เดียวกัน ซิงก์กับเสียง เพิ่มบทสนทนาและคำบรรยายตามภาษาในพื้นที่ทำงานเลตเตอริงในตัว แล้วส่งออกเป็นไฟล์ .comics เดียว — รูปแบบ zip แบบพกพาที่เครื่องเล่นที่รองรับสามารถเล่นแบบออฟไลน์ได้โดยไม่ต้องมีเซิร์ฟเวอร์

รองรับโปรเจกต์ Puzzle ด้วยเช่นกัน: บอร์ดปริศนาแบบลากและซูมที่สร้างจากภาพเลเยอร์เดียวกัน

ฟีเจอร์
• โปรเจกต์สองประเภท: Comics (เลื่อนดู แอนิเมชัน ซิงก์เสียง) และ Puzzle (ลากและซูม)
• เลเยอร์ที่มีภาพแยกตามภาษา จัดลำดับใหม่ได้ ควบคุมการแสดงผล แปลงรูปบนแคนวาสได้โดยตรง
• แอนิเมชัน Translate / Rotate / Scale / Alpha บนไทม์ไลน์เดียวกัน
• แทร็กเสียงที่ผูกกับตำแหน่งบนไทม์ไลน์ พร้อมปิดเสียงทั้งหมดได้
• รายการภาษาที่รองรับเป็นแบบไดนามิกและขยายได้ ไม่ใช่รายการตายตัว
• เลิกทำ/ทำซ้ำ กล่องโต้ตอบเปิด/บันทึกของระบบ ซูมแคนวาสด้วยการบีบนิ้ว/แพน/ล้อเลื่อน
• โปรเจกต์และรูปแบบไฟล์เดียวกันเปิดได้เหมือนกันทุกแพลตฟอร์ม

แพลตฟอร์ม
Comics Editor ทำงานเหมือนกันบน Windows, macOS, Linux, iPad, iPhone และ Android โดยอินเทอร์เฟซจะปรับตัวจากพื้นที่ทำงานเดสก์ท็อปแบบเต็มรูปแบบไปเป็นมุมมองแคนวาสเดียวบนโทรศัพท์

เหมาะสำหรับใคร
สร้างขึ้นสำหรับผู้ผลิตการ์ตูน นักเลตเตอริง และทีมโลคัลไลเซชันที่ทำงานหลายภาษาและหลายแพลตฟอร์ม ที่ต้องการเครื่องมือแก้ไขเดียวและรูปแบบไฟล์พกพาเดียวสำหรับทุกอุปกรณ์เป้าหมาย

ไม่ต้องมีบัญชี ไม่ต้องเข้าสู่ระบบ ไม่มีโฆษณา ข้อมูลโปรเจกต์ทั้งหมดอยู่บนอุปกรณ์ของคุณเท่านั้น

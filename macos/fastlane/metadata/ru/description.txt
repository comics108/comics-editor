Comics Editor — инструмент для создания анимированных многоязычных комиксов и интерактивных пазлов: один проект — один портативный файл, который воспроизводится где угодно.

Собирайте страницу из слоёв — фон, персонажи, реплики, подписи, звук — и оживляйте её анимациями Translate (перемещение), Rotate (поворот), Scale (масштаб) и Alpha (прозрачность) на общей временной шкале, синхронизированной со звуком. Добавляйте текст реплик и подписей на нужном языке во встроенном режиме леттеринга и экспортируйте единый файл .comics — портативный zip-формат, который любой совместимый плеер воспроизведёт офлайн, без сервера.

Поддерживаются и проекты Puzzle — интерактивные пазлы с масштабированием и перетаскиванием фрагментов на основе той же слоёной графики.

ВОЗМОЖНОСТИ
• Два типа проектов: Comics (анимированная лента со звуком) и Puzzle (перетаскивание и масштаб)
• Слои с отдельной картинкой на язык, изменение порядка, видимость, трансформация на холсте
• Анимации Translate / Rotate / Scale / Alpha на общей временной шкале
• Звуковые дорожки, привязанные к позиции на шкале, глобальное отключение звука
• Динамический, расширяемый список поддерживаемых языков — не фиксированный набор
• Undo/redo, системные диалоги открытия/сохранения, зум холста (пинч, колесо, панорамирование)
• Один и тот же проект и формат файла одинаково открываются на любой платформе

ПЛАТФОРМЫ
Comics Editor одинаково работает на Windows, macOS, Linux, iPad, iPhone и Android — интерфейс перестраивается от полноценного десктопного рабочего пространства до сфокусированного вида на телефоне.

ДЛЯ КОГО
Инструмент для продюсеров комиксов, леттереров и команд локализации, которым нужен один редактор и один портативный формат файла для любой целевой платформы.

Без аккаунта, без входа, без рекламы. Все данные проекта остаются на вашем устройстве.
